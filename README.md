# Proyecto_Programado_Mecanica_Teorica_II
Proyecto programado del  curso "Mecánica Teórica II" sobre dinámica de vortices puntuales bidimensionales y validación de sus cantidades conservadas usando el método numérico Runge-Kutta de orden 4. Proyecto realizado por Isaac Flores y Diego Hurtado de la Universidad de Costa Rica.
